# Cape Fear Collective

Cape Fear Collective — Premium spec portfolio project by Rising Tide Digital LLC. Demonstrates luxury wedding photography studio website. React + Tailwind CSS + Vite. Sophisticated, clean aesthetic targeting the high-spend wedding market. Live at: [GitHub Pages URL]

## Stack

- **Vite** + **React 18**
- **Tailwind CSS v3** with custom brand design system
- **React Router v6** for client-side routing
- **Google Fonts** — Cormorant Garamond + Jost
- Deployed via **gh-pages** to GitHub Pages

## Local Development

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

```bash
npm run deploy
```
